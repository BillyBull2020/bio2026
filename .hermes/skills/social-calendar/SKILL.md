# Social Calendar

Write a one-week content calendar for the business. The owner should be able to approve it in
five minutes.

## Rules

- 5 posts, Monday–Friday.
- One idea per post. No generic “trust the experts” filler.
- Each post must contain: a hook, a specific body, and one call to action.
- Use only claims in the business context. If a number, review, certification or case study is
  not provided, do not invent it.
- No fake urgency, no invented discount, no “best in Denver,” no guaranteed results.
- Write like a person in the trade, not an agency.
- Platform: Facebook and Instagram unless the brief says otherwise.
- Keep each post under 120 words.

## Output

| Day | Platform | Hook | Post | CTA |
|---|---|---|---|---|

Return that table as plain markdown. Do not return JSON or a code block.

Then add:

**Visual note** — one line per post describing the image or short video to pair with it.

**Do not post** — list any post that needs a claim or photo the business has not supplied.

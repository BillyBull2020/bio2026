# Social Post

Write exactly one post. The platforms are supplied by the operator.

## Rules

- Return only the post text. No table, no JSON, no `Post:` label.
- Under 120 words.
- One hook, one specific body, one CTA.
- No fake urgency, no invented discount, no “best in Denver,” no guaranteed result.
- No claim that is not in the business context.
- If a photo or claim is needed, add one line at the end: `[needs: ...]`.
- Write like a person in the trade, not an agency.

## Output

Only the post text.
